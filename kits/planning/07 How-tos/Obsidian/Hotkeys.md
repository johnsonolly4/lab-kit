# Hotkeys

> [!tip] One rule: `Alt` + the first letter of what you want
> **H** home, **D** day, **F** find, **Z** Zotero paper, **N** note, **T** to-do, **L** lab entry, **U** update, **C** citation, **S** snippet.

These are suggestions. Lab Kit never sets a hotkey for you, so nothing changes until you do it yourself (see the end of this note).

| Keys | Does | Command to pick in Settings → Hotkeys |
|---|---|---|
| `Alt+H` | Homepage | Notebook Navigator: open the homepage |
| `Alt+D` | Today's note | Daily notes: Open today's daily note |
| `Alt+F` | Search | Omnisearch: Vault search |
| `Alt+Z` | Open a paper's note | ZotLit: open the literature note |
| `Alt+N` | Quick note into the inbox | Lab Kit: Quick capture |
| `Alt+T` | New to-do | Lab Kit: New to-do |
| `Alt+L` | New lab entry | Lab Kit: New lab entry |
| `Alt+U` | Update this paper's highlights | ZotLit: Update literature note |
| `Alt+C` | Insert a citation | ZotLit: insert citation |
| `Alt+S` | Insert a lab snippet | Templater: Insert snippet.md (Settings → Lab Kit → **Check hotkeys** shows which of these keys are set) |
| `Ctrl+E` | Switch between reading and editing | Obsidian's own key, nothing to set |

No key suggested (set your own if you use them a lot): Lab Kit: Add to shopping list, Sort inbox, New meeting, New project, New project note, Roll over to-dos now, Archive old to-dos.

In Zotero: `1` yellow, `2` red, `3` green.

## Set one

1. Obsidian → **Settings → Hotkeys**.
2. Search for the command name from the table.
3. Click **+** and press the keys. If Obsidian says the key is already used, pick another or remove the other one.

On a Mac, `Alt` is `Option`. If a key types a symbol instead of running the command, choose a different key for that command.

See also: [[Setting up a computer]] for the Windows / Mac differences.
