`BUTTON[new-meeting-series, new-meeting, go-deck]`

> [!note]- How meetings work
> - Each meeting you hold regularly is a **series**: a folder here with a hub note (interval, day, first date, deck location).
> - Press **New meeting series** to make one. It asks the name, how often, which day, the first date and where the deck is.
> - **New meeting note** asks which series, then fills the note with the experiments, finished to-dos and papers read since the last meeting.
> - **Meeting deck** opens the deck of a series.
