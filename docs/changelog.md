# Lab notebook kit: changelog

## Unreleased
- **Close experiment: PDF folders are kept per device** (plugin; owner board 5, 2026-10-20; unit tests, NOT tried with Sync on two devices): the list used to be in `data.json`, which Obsidian Sync copies to every device, so a Windows path reached the Mac. It is now kept in Obsidian's local storage on each device (the same way the board remembers its folded tray). The first time a device starts it copies the list from `data.json` once; `data.json` keeps that old list and is not changed by this setting any more. After that each device has its own list. The row in Settings says so.
