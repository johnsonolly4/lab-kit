# Lab notebook kit: changelog

## Unreleased
- **Snippet icons is its own page, with an icon picker** (Settings → Lab Kit → Snippet menu → Snippet icons): each snippet row shows its icon, and **Choose…** opens a searchable grid of the icons Obsidian has (Lucide); typing a name still works. The boxes now show every snippet's own icon as the grey default, including the token templates (variant matrix, sample list, sampling timetable and copies), which showed an empty box before. Empty still keeps the snippet's own icon.
- **One-off meetings use a smaller note; a series can use its own meeting template** (planning kit): a one-off meeting is made from the new kit template **One-off meeting** (To discuss, Flagged for this meeting, Notes). New meeting series asks one more question at the end, the name of a template note for the series (Enter = the kit's **Meeting** template); it is written as `template` on the series hub and can be edited there. A series with a `template` uses that note for its meeting notes (a one-off hub too); a name that finds no note falls back to the kit's template with a notice. Start your own template as a copy of the kit's Meeting template, because it reads the same hand-over. Series hubs you already have get no `template` line: add `template: Name` yourself.
- **Hub buttons** (planning kit, new hubs): project, topic and meeting series hubs have a **back link** to the hub one folder up (found by folder when you look at it, so renaming a folder cannot break it); a topic hub has **New concept**, which files the note in that topic without asking the topic; a meeting series hub has **Extra meeting now**. Hubs you already have get them when Tidy up notes can update hub bodies (planned, next phases) or when you add the three blocks (`show: back-to-hub`, `show: topic-actions`, `show: series-actions`) yourself.
- **Home has no focus lines; project cards stack their chips** (planning kit): the three "Today's focus" boxes and the **Clear for tomorrow** button are gone from the Home note (existing Home notes keep them until you delete them or use Replace with new version…); the How my vault works and Vault spec notes no longer describe them or say the Shopping list is for lab orders only. On the Projects overview cards the status and deadline chips sit one above the other at the right.
- **Sample codes from every table** (NMR, GPC, DLS, Methods-folder methods, Combined results): the Sample codes box is now filled with the codes of every table in the note that holds sample codes, not just the first it found (a Sample list used to hide a Sampling timetable). When there is more than one, a new **Codes from** choice lists "All of them" (the default) and each table by its title; pick one to narrow it, or edit the box and your text is used. A table says it holds codes with a new calc block option, `codes: column A` or `codes: cells` (any table, from any snippet or made by hand); the Sample list, Sampling timetable, Variant naming matrix and the sample tables the method snippets insert carry it, so one extra line appears in new tables. Older tables named samples / sampling are still found. New reference `docs/snippet-syntax.md` for the token, calc block and method note syntax. Review update… for the six snippets and the scripts. Tests only, not seen in Obsidian
- **Check setup finds a Meta Bind button that does something else than the kit's** (planning kit): a new row, **Meta Bind buttons that differ from the kit**, lists each button of the kit's whose installed version (same id) opens another note or runs another command, for example `go-meetings opens [[Weekly meetings]] (kit: opens [[Meetings]])`. **Fix** puts the kit's action on it after you confirm; the button's label and look stay. Buttons that are missing keep their own row and Fix, your own buttons are never listed. Only the fields the kit sets are compared, so a field Meta Bind adds itself doesn't count. Restart Obsidian after Fix, Meta Bind loads its buttons at start-up. Tests only, not seen in Obsidian (Meta Bind's real settings and reload)
- **Project hub fixes**: (1) **Show all N** / **Show the last N** on the hub tiles no longer opens the tile for editing when you click it in Live Preview, and Obsidian's "Edit this block" icon is hidden on those tiles so it can't overlap the button; (2) the hub's **New to-do** and **New note** buttons sit in one row (a new `show: project-actions` card; new hubs get it, an existing hub keeps its two stacked buttons until you replace the line with a vault-card block `show: project-actions`); (3) **Tidy up notes** now adds the template's classes: project notes get `vt`, project hubs get `vt` and `project` (even when nothing else is missing), and when it changes a to-do, meeting note, series hub or hub note anyway it adds `vt` too; your own classes stay. Needs Review update… for the planning theme and the Project hub template. Tests only, not seen in Obsidian: the button position, the Live Preview click, the hidden icon (Obsidian's own class names)
- **Manage kit files renames a file when the kit renames it** (first case: **Weekly meeting.md** is now **Meeting.md**). Before, an update rewrote the text in place and the file kept its old name. Now Review update… / Update all moves your copy to the new name (old copy in the backups, your edits merged in). Not moved: a file you kept, a file with unresolved edits (it stays where it is until you resolve it), or when a file with the new name already exists. The report lists them under "Renamed". Tests only, not seen in Obsidian
- **Kept files: Keep leaves the update on offer** (Manage kit files): **Keep** now writes nothing and remembers your choice; the row keeps a quiet "Newer kit version available (you kept yours)" badge and the Compare… and Update… buttons, so you can still update later. A later kit change shows a new update as before. Also: the Sort inbox picker and the calc cell editor's coloured copy have CSS fixes. Tests only (CSS not seen in Obsidian)
- **Tidy up notes: a project folder with no hub**: a folder under Projects that holds notes but no hub note (it was deleted) is listed under "Project folders without a hub note"; applying makes `<folder>/<folder>.md` from the Project hub template (kind, Status, deadline, buttons, tiles). - **Sample list and timetable forms**: the technique toggles are headed "Also add (appended below)", so it is clear the tables go under the sample table
